## Como configurar seu bot

O guia discord.js tem [instruções para configurar um aplicativo de bot](https://discordjs.guide/preparations/setting-up-a-bot-application.html#creating-your-bot). Depois de seguir as instruções, você pode colar o token do bot no arquivo "config.json". A próxima página do guia mostra como convidar o bot para um servidor.
